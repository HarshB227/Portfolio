# Harsh Bhavsar — Portfolio

Personal portfolio of **Harsh Bhavsar**, MSc Data Science graduate (University of Roehampton) seeking Graduate / Internship **Generative AI Developer** roles in London.

🔗 **Live site:** [harshb227.github.io/Portfolio](https://harshb227.github.io/Portfolio)

## Features

- Interactive 3D particle background built with **Three.js** (reacts to mouse movement and scroll)
- Typing animation cycling through role titles
- 3D tilt effect on cards
- Scroll-triggered reveal animations
- Fully responsive, single-file build — no frameworks, no build step

## Tech Stack

- HTML5, CSS3 (custom properties, grid, animations)
- Vanilla JavaScript (ES modules, IntersectionObserver)
- [Three.js](https://threejs.org/) r160 via import map (unpkg CDN)

## Run Locally

```bash
git clone https://github.com/HarshB227/Portfolio.git
cd Portfolio
python -m http.server 8000
```

Then open `http://localhost:8000`. (A local server is needed because Three.js loads as an ES module.)

## Deployment

Hosted on **GitHub Pages** — push to `main` and the site updates automatically.
